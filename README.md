# 💆‍♀️ Beauty Center

A full-stack web application for managing appointments in an aesthetic and beauty center.

The platform allows clients to **browse beauty services, book appointments online, manage their appointments, and receive notifications**, while administrators can manage appointments, clients, services, offers, and statistics.

## ✨ Features

### Client

* 🔐 Login & Registration
* 💆 Browse beauty services
* 📅 Book appointments online
* 📋 View and manage appointments
* 🔔 Receive notifications
* 🎁 View offers and discounts
* ⚙️ Manage profile and account settings

### Admin

* 📊 Dashboard with statistics
* 📅 Manage appointments
* 👥 Manage clients
* 💆 Manage services
* 🎁 Manage offers & discounts
* ✅ Confirm or ❌ cancel appointments
* ⚙️ Manage account settings

## 🛠️ Technologies

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT
* **Tools:** Git, GitHub, Postman, Figma
